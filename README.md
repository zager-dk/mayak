# Маяк VPN

Собственный VPN-сервис на базе **AmneziaWG** и программа-администратор для Windows.

- **Пользователи подключаются** обычными приложениями: AmneziaVPN (файл `.vpn` или ключ `vpn://`) на Windows и Android, AmneziaWG (файл `.conf`) на iPhone и Mac.
- **Вы управляете** сервером из `MayakVPN.exe`. Программа ставит VPN на арендованный сервер, ведёт список постоянных пользователей и их устройств, выдаёт файлы и QR-коды и ограничивает скорость каждого устройства.

Сервер устанавливается **в той же раскладке, что делает официальное приложение AmneziaVPN** (контейнер `amnezia-awg2`). Поэтому его можно открыть и в AmneziaVPN, а Маяк увидит подключения, выданные оттуда.

---

## Быстрый старт

1. **Сервер.** Арендуйте VPS за пределами России: Ubuntu 22.04/24.04 или Debian 12, 1 vCPU / 1 ГБ RAM хватает на десятки пользователей. Нужен доступ по SSH под `root` (или пользователь с `sudo` без пароля).
2. **Программа.** Запустите `MayakVPN.exe` (или соберите: `build.cmd`, см. ниже).
3. **«+ Добавить»** слева: IP сервера, логин, пароль или SSH-ключ.
4. **«Установить VPN…»**: выберите версию протокола, порт и лимит скорости по умолчанию. Установка занимает 3–7 минут.
5. Если у хостинга есть внешний файрвол в панели управления, **откройте UDP-порт**, который показан после установки.
6. **«+ Пользователь»** → **«+ Устройство»**. Выберите тип (Windows, Android, iPhone, Mac…), и Маяк:
   - создаст ключи и добавит устройство на сервер без перезапуска;
   - сохранит файл в `Документы\Маяк VPN\<сервер>\<пользователь>\`;
   - покажет QR-код и инструкцию для этого типа устройства.

| Устройство | Файл | Приложение |
|---|---|---|
| Windows, Android, Linux | `.vpn` (внутри ключ `vpn://`) | AmneziaVPN |
| iPhone, Mac | `.conf` | AmneziaWG или AmneziaVPN |

Файл в другом формате можно выгрузить в окне «Выдать файл / QR» в любой момент.

## Возможности

- **Постоянные пользователи**: имя, заметка (контакт, «оплачено до…»), несколько устройств на человека.
- **Постоянный список людей, общий для всех серверов** («Список людей» слева). Людей и их устройства заводите один раз. На любом сервере «Выдать доступ по списку…» одной кнопкой заводит недостающих пользователей и устройства (одним обновлением конфига) и сохраняет файлы для всех отмеченных: папка на человека, `.vpn` для Windows/Android, `.conf` + QR-картинка для iPhone/Mac и сводка «Доступы.txt». Повторная выдача ничего не дублирует и не меняет ключи; добавленное в список устройство выдаётся отдельно. Пользователи, заведённые вручную, сами попадают в список, а «Взять пользователей с сервера» переносит в него уже существующих.
- **Приостановка и возобновление** доступа пользователя или отдельного устройства без смены ключей.
- **Повторная выдача файла** в любой момент (потерял телефон → «Выдать файл / QR»).
- **Лимит скорости на каждое устройство**, отдельно на скачивание и отдачу. По умолчанию 35 Мбит/с: YouTube в 4K требует около 20–25. Лимит применяется сразу, переподключаться не нужно.
- **Статус**: в сети / когда был, трафик по каждому устройству. Данные обновляются раз в минуту.
- **Подключения из AmneziaVPN**: если они есть, над списком пользователей появляется строка; их можно отозвать или привязать к пользователю.
- **Два протокола** на выбор при установке:
  - **AWG 2.0** (по умолчанию) работает в большинстве актуальных AmneziaVPN и AmneziaWG;
  - **AWG 3.1** даёт защиту заголовков и случайные тайминги, но нужны самые свежие клиенты.
- **Два протокола в одном файле.** Рядом с AmneziaWG ставится **Xray (VLESS + Reality + XHTTP)** поверх TCP: трафик выглядит как обращение к обычному сайту. Файл `.vpn` содержит оба протокола, и в AmneziaVPN между ними можно переключаться. Для сторонних приложений (v2RayTun, Happ, Streisand, Hiddify) есть ссылка `vless://` и QR.
- **Встроенная проверка протоколов** (вкладка «Проверка»). Маяк прямо с вашего компьютера:
  - для AmneziaWG проводит настоящее рукопожатие с маскировкой AWG 2.0/3.1, гоняет 400 пакетов через туннель и делает DNS-запрос (видна и блокировка, и «заморозка» после первых килобайт);
  - для Xray поднимает официальный `xray.exe` (скачивается один раз с GitHub, SHA-256 сверяется), соединяется через Reality и скачивает 30 МБ;
  - показывает, с какого адреса сервер видит компьютер (чтобы не проверять случайно через чужой VPN), и хранит историю по сетям («Дом, Ростелеком», «МТС, мобильный»…).
  - работает и без SSH, в том числе после перезапуска Маяка: проверочная учётка создаётся при первом подключении, а нужные для проверки данные (без ключей пользователей) хранятся на компьютере под DPAPI.
- **Проверка адреса до установки** («Проверить адрес…» слева или в окне добавления сервера). С 2026 года из России не маршрутизируются целые диапазоны зарубежных хостингов, и такой сервер бесполезен, как его ни настраивай. Маяк проверяет IP с вашего компьютера и со всех входных серверов из списка (TCP 22 и 443, отличая «нет ответа» от «порт закрыт»), сверяет с контрольными адресами и говорит прямо: подходит напрямую, только через вход или не подходит.
- **Вход через другой сервер (каскад).** Если IP основного сервера заблокирован у пользователей, Маяк настраивает входной VPS (например, Timeweb в Москве): он только пересылает зашифрованный трафик на основной сервер правилами ядра (DNAT), ничего не расшифровывает и не хранит ключей. Адрес входа автоматически попадает во все файлы. Пересылка переживает перезагрузку (служба `mayak-relay`).
- **SSH через посредника.** Если зарубежный сервер не открывается из вашей сети, в настройках сервера выберите «Как Маяк подключается к серверу → Через …»: Маяк ходит к нему SSH-туннелем через другой сервер из списка (как `ssh -J`), шифрование сквозное. Работает и для нового, ещё не настроенного сервера — можно установить VPN, не включая сторонний VPN.
- **Несколько серверов** в одном окне.

## Как это устроено

```
 MayakVPN.exe (Windows)                     VPS
 ┌──────────────────────┐   SSH     ┌──────────────────────────────────────────┐
 │ WPF-интерфейс        │──────────▶│ Docker                                   │
 │ Mayak.Core:          │           │  └─ контейнер amnezia-awg2               │
 │  · X25519-ключи      │           │       amneziawg-go (userspace), awg0     │
 │  · vpn:// / .conf    │           │       /opt/amnezia/awg/awg0.conf         │
 │  · AWG 2.0 / 3.1     │           │       /opt/amnezia/awg/mayak.json  ◀─ база│
 │  · SSH.NET           │           │       /opt/amnezia/awg/mayak_tc.sh ◀─ tc │
 └──────────────────────┘           └──────────────────────────────────────────┘
          ▲                                         ▲  UDP-порт
          │ .vpn / .conf / QR                       │
     пользователи ──── AmneziaVPN / AmneziaWG ──────┘
```

### Файлы на сервере (внутри контейнера `amnezia-awg2`)

| Файл | Назначение |
|---|---|
| `/opt/amnezia/awg/awg0.conf` | Конфиг AmneziaWG: параметры маскировки и `[Peer]` на каждое устройство |
| `/opt/amnezia/awg/wireguard_*.key` | Ключи сервера и общий PSK (как у Amnezia) |
| `/opt/amnezia/awg/clientsTable` | Имена устройств для официального приложения AmneziaVPN |
| `/opt/amnezia/awg/mayak.json` | **База Маяка**: пользователи, устройства, лимиты, настройки (права 600) |
| `/opt/amnezia/awg/mayak_limits` | Лимиты в формате для `tc` |
| `/opt/amnezia/awg/mayak_tc.sh` | Применяет лимиты, запускается при старте контейнера |
| `/opt/amnezia/start.sh` | Стартовый скрипт контейнера (Amnezia + вызов лимитов) |

Xray — контейнер `amnezia-xray`, данные в томе `amnezia-xray-data` (`/opt/amnezia/xray`): `server.json`, ключи Reality, UUID владельца. Клиенты Маяка помечены в `server.json` полем `email: "mayak:<id>"`, остальные (выданные из AmneziaVPN) Маяк не трогает. Каждый новый `server.json` сначала проверяется `xray -test`, при сбое запуска возвращается прежний.

База лежит на сервере, а не на компьютере администратора. Можно управлять с нескольких ПК, а при переустановке Windows ничего не теряется. Нужно лишь заново добавить сервер в список.

### Лимиты скорости

Внутри контейнера на интерфейсе `awg0`:

- **скачивание** (сервер → устройство): HTB-класс на каждое устройство (фильтр по IP в VPN) + `fq_codel`, чтобы не росли задержки;
- **отдача** (устройство → сервер): policer на входящей очереди.

Если серверу назначили лимиты, а потом его открыли в AmneziaVPN и пересоздали контейнер, Маяк при следующем изменении сам вернёт `tc` и вызов из `start.sh`.

### Совместимость с форматом Amnezia

Формат проверен по исходникам [amnezia-client](https://github.com/amnezia-vpn/amnezia-client) (ветка 5.x и релиз 4.8.19):

- `vpn://` = `base64url( qCompress(JSON) )`, где `qCompress` — 4 байта длины (big-endian) + zlib;
- JSON: `containers[0].awg` с параметрами `Jc/Jmin/Jmax/S1–S4/H1–H4/I1–I5` и строкой `last_config` (ключи клиента, `config`, `mtu`…), `defaultContainer = amnezia-awg2`;
- QR-коды для AmneziaVPN: куски по 850 байт с заголовком `1984 / всего / номер` (QDataStream), как `qrCodeUtils::generateQrCodeImageSeries`.

## Сборка

Нужен .NET 8 SDK (или новее).

```bat
build.cmd
```

Скрипт при необходимости поставит SDK через `winget`, прогонит самотест ядра и соберёт **один файл** `dist\MayakVPN.exe`. Ему не нужен установленный .NET.

Вручную:

```bash
dotnet run --project tests/Mayak.SelfTest -- samples     # самотест + примеры файлов в ./samples
dotnet publish src/MayakVPN/MayakVPN.csproj -c Release -o dist
```

На GitHub сборку делает `.github/workflows/build.yml`: готовый `.exe` появляется в артефактах.

## Что можно доработать дальше

- **Собственный клиент «Маяк VPN».** Форк `amnezia-client` со своим названием, иконкой и вшитым адресом. Пользователь вводит только ключ или сканирует QR. Обратите внимание: amnezia-client распространяется под GPLv3, значит исходники форка тоже нужно открыть.
- Срок действия доступа («оплачено до») с автоматической приостановкой. Поле «Заметка» уже есть, нужна дата и задача по расписанию на сервере.
- Лимиты трафика в ГБ за месяц (счётчики уже приходят из `awg show dump`).
- Telegram-бот для выдачи ключей пользователям.
- Hysteria2 (QUIC) третьим протоколом и выбор транспорта Xray (XHTTP / raw+Vision) прямо в Маяке.
- Лимиты скорости для Xray (сейчас ограничивается только AmneziaWG).

## Решение проблем

- **«sudo без пароля»**: подключайтесь под `root` или добавьте строку `user ALL=(ALL) NOPASSWD:ALL` через `visudo`.
- **«Не удалось собрать контейнер»**: чаще всего это лимит Docker Hub. Повторите через 10–30 минут.
- **Устройство «ещё не подключалось»**: проверьте UDP-порт в файрволе хостинга и время на устройстве. Если стоит AWG 3.1, обновите приложение-клиент.
- **«Отпечаток ключа сервера изменился»**: если вы переустанавливали ОС на сервере, нажмите «Изменить» → «Сбросить». Иначе это может быть подмена.
- **«Промежуточный сервер … не смог соединиться»**: посредник не видит этот сервер. Выполните в консоли посредника команду из сообщения; `FAIL` значит, что IP сервера заблокирован и из дата-центра посредника, и нужен другой сервер.
- Журнал всех операций: вкладка «Журнал». Аварийный лог: `%APPDATA%\MayakVPN\crash.log`.

## Безопасность

- Пароли SSH хранятся только на вашем ПК, зашифрованы Windows DPAPI.
- Ключ сервера запоминается при первом подключении. Если он изменится, Маяк откажется подключаться.
- Приватные ключи устройств хранятся в `mayak.json` на сервере (только root, права 600), чтобы файл можно было выдать повторно. Кто получил root на сервере, и так управляет всем VPN.
