# Первое подключение

## Выдать вход в приложение

1. В кабинете администратора найдите человека. Если аккаунт выключен или срок доступа закончился, сначала отдельно включите аккаунт и восстановите действующий срок доступа.
2. Нажмите «Код для входа» и передайте одноразовый код. Новый код заменяет предыдущий неиспользованный. В приложении Маяк на Android или Windows введите код в поле входа. Приглашение само не включает доступ и не меняет существующие устройства или ключи.
3. Для входа в веб-кабинет через Telegram продолжает работать прежний путь.

## Выдать подписку на устройство

В кабинете пользователя откройте активное устройство → «Ключ» → «Подписка для v2RayTun». Создание ссылки подтверждается отдельно: новая ссылка заменит прежнюю, если она уже выпускалась. Скопируйте ссылку в приложении или откройте её в v2RayTun с того же устройства. Внешний импорт проверяется в пилоте; эта инструкция не подтверждает работу на каждом телефоне.

«Отозвать ссылку» останавливает дальнейшее обновление подписки. Уже загруженные в клиент конфигурации продолжат работать, пока устройство включено. Чтобы полностью прекратить доступ, выключите или удалите само устройство.

Если выпуск недоступен, UI показывает ответ API как ошибку; не считайте неудачный запрос созданной ссылкой. Подписка не выдаётся для выключенного устройства, неактивного аккаунта или без настроенного VLESS endpoint. При недоступном выходе сначала проверьте состояние текущего cluster endpoint в кабинете администратора.

## Секреты ссылок

Ссылку подписки можно считать секретом доступа. Не публикуйте её в тикетах и чатах. Reverse proxy перед production выпуском должен скрывать или редактировать токен из пути `/sub/{token}` в access/error logs и tracing; см. [инструкцию по журналированию секретного пути](SUBSCRIPTION_TOKEN_LOGGING.md). Production-конфигурация этим изменением не меняется.
