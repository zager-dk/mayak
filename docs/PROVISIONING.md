# Установка пустого сервера из админки

В разделе «Серверы» выберите «Пустой сервер». Первый этап получает SSH fingerprint без пароля; сверяйте его с консолью провайдера и явно подтверждайте доверие. Затем read-only проверка требует публичный IPv4, Ubuntu 22.04/24.04 x86_64, root или passwordless sudo, свободные кластерные порты, отсутствие контейнеров, VPN и агента. Установка доступна только активному администратору или владельцу.

Перед запуском проверьте имя, IPv4, SSH-пользователя, порты и галочку «новый пустой сервер». Пароль используется только в памяти текущего API-процесса и очищается после передачи ограниченной фоновой задаче; он не записывается в БД, аудит, статус задачи или localStorage. После перезапуска API задача помечается прерванной и пароль нужно ввести заново.

Новый сервер остаётся неактивным. Агент должен сообщить identity AWG/Xray, совпадающую с кластером, и подтвердить применение актуальной ревизии. Затем администратор может отдельно включить выход. Первый сервер в пустом кластере задаёт общую identity; следующие серверы клонируют её только на новом узле. Прерванная или частично завершённая установка не удаляет файлы и не поддерживает автоматическую destructive-переустановку: сначала проверьте сервер вручную.

**Ограничение первой версии:** SSH поддерживает пароль, серверы только Ubuntu 22.04/24.04 x86_64 и публичный IPv4; ключи SSH, IPv6, несколько одновременно устанавливаемых узлов сверх лимита очереди и внешняя проверка доступности VPN не реализованы. Успешный статус означает, что агент связался, совпала identity и применена ревизия; он сам по себе не доказывает доступность портов из интернета.
