# Путь пользователя в первом выпуске

## Вход по приглашению

Приглашение действует 14 дней и используется один раз. На странице `/my/` код можно ввести из ссылки или вручную. Открытие страницы, предпросмотр ссылки и скачивание установщика его не погашают.

Для Windows и Android можно скачать приложение «Маяк» и ввести код в приложении. Приложение сохраняет сеанс и получает ключ подписки; после этого код уже нельзя использовать в кабинете. Если пользователь выбрал кабинет, нажатие «Открыть кабинет и использовать код» погашает приглашение. Повторно войти в «Маяк» по этому коду нельзя. Если приглашение уже использовано приложением, для входа на сайт попросите администратора выдать новое приглашение тому же аккаунту либо используйте кабинет, в котором пользователь уже вошёл. Если код погашен в кабинете, там можно получить действующий ключ через «Показать ключ для приложения» и добавить его в приложении «Маяк» через «Добавить» → «Вставить ключ». Сам ключ — секрет, его нельзя пересылать.

Не отправляйте один код одновременно пользователю приложения и пользователю кабинета. Если код был погашен другим способом или истёк, попросите администратора выпустить новый.

## Статус сервера в кабинете

Поле API `ready` означает, что в конфигурации есть кластер. Оно не проверяет внешний доступ к VPN и не сообщает о наличии свободного выхода. Если кластер не настроен, кабинет скрывает действие добавления устройства и просит связаться с администратором. Если настройка есть, но адрес/свободный выход неизвестен, интерфейс сообщает об этом и показывает ошибку назначения, если сервер её вернул. Недавний сигнал узла также не гарантирует, что VPN-соединение доступно.

Если вход по приглашению возвращает 403, проверьте у администратора одобрение доступа и срок его действия. Повторная проверка сети не исправит этот статус.

## Приложения и платформы

- Windows: same-origin загрузка `MayakVPN_5.1.0.4_windows_x64.exe`. Это неподписанный установщик x64; Windows может показать предупреждение издателя. Перед массовой раздачей нужно подтвердить, что фактически опубликованный файл существует и прошёл выпускную проверку.
- Android: `Mayak-Android-5.1.0.4-arm64-v8a-api28-signed.apk` — подписанный пакет ARM64 для Android API 28 и выше. На устройстве нужно разрешить установку этого APK, если система спросит.
- iPhone/iPad: сначала войти в кабинет, добавить отдельное устройство и выбрать AmneziaWG для файла `.conf` либо DefaultVPN для ключа `vpn://`. DefaultVPN требует iOS 16 или новее; AmneziaWG — iOS 15 или новее. Ссылки ведут на официальные карточки App Store. Список приложений и наличие в конкретном регионе могут отличаться.
- Mac: добавить устройство типа Mac и импортировать его `.conf` в AmneziaWG. Официальная карточка AmneziaWG указывает поддержку macOS 12 и новее. Встроенный DefaultVPN предназначен для iPhone/iPad, поэтому для macOS он не предлагается.
- v2RayTun: после входа в кабинет добавить устройство и в его карточке открыть «Подписка для v2RayTun» → «Создать / перевыпустить ссылку». Можно скопировать VLESS-ссылку или открыть её в установленном v2RayTun. Она отдельна от ключей `.conf` и `vpn://`; её можно отозвать из той же карточки. При перевыпуске прежняя subscription-ссылка заменяется.

В этой версии нет входа по email/паролю и нет SSO между сайтом и приложением. Приложение можно установить по ссылке, но системный автозапуск приложения из кабинета не обещается.

## Проверенные первичные источники

- [AmneziaWG в App Store](https://apps.apple.com/app/amneziawg/id6478942365) — карточка указывает iOS 15+, iPhone/iPad и macOS 12+.
- [DefaultVPN в App Store](https://apps.apple.com/app/defaultvpn/id6744725017) — карточка указывает iOS 16+ и объясняет, что приложению нужен ключ конфигурации.
- [Официальная инструкция AmneziaWG](https://docs.amnezia.org/documentation/instructions/use-amneziawg-app/) — импорт `.conf` из файла на iPhone, iPad и Mac.
- [Официальная инструкция DefaultVPN / AmneziaVPN](https://docs.amnezia.org/documentation/instructions/first-connect-amnezia-premium/) — DefaultVPN и AmneziaVPN используют subscription key `vpn://`; AmneziaWG получает конфигурацию из файла и не принимает ключ `vpn://`.
- [Альтернативные клиенты Amnezia](https://docs.amnezia.org/documentation/alternative-clients/) — официальный список клиентов для AmneziaWG.

## Что ещё не доказано этой страницей

Наличие ссылки в интерфейсе само по себе не доказывает доступность файла. До выдачи пользователям нужно подтвердить production HTTP download, подпись/хэш опубликованных пакетов, реальный вход Android и Windows, импорт конфигурации на iPhone/Mac и успешное VPN-соединение. Локальная fixture-проверка не подменяет эти проверки. Автоматический выбор свободного зарубежного сервера и переход между серверами в приложении здесь не проверяются.
