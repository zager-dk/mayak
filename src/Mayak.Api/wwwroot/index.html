Как это работает

Приглашение одноразовое. Оно расходуется только после отправки формы регистрации или использования в приложении.

1

Введите приглашение

Откройте полученную ссылку в кабинете или введите код в приложении.

2

Выберите устройство

Ниже: приложение для Windows или Android, а для iPhone и Mac доступ в кабинете.

3

Подключитесь

В приложении Маяк нажмите большую кнопку. На iPhone и Mac включите доступ в AmneziaWG по инструкции из кабинета.

Три способа подключиться

Выберите устройство

Для Windows и Android есть приложение Маяк. Для iPhone и Mac Маяк выдаёт доступ в кабинете, а подключение идёт через приложение AmneziaWG из App Store.
